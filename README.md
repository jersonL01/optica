# OptiClinic

Web demo para una optica profesional, construida con React, TypeScript, Vite y Tailwind CSS.

## Secciones

- Inicio con hero comercial, servicios, productos, experiencia, reserva y contacto.
- Pagina de servicios con grilla de atenciones y flujo de trabajo.
- Pagina de productos con categorias, atributos y tecnologias de cristales.
- Pagina de reserva con formulario funcional en frontend.
- Pagina de contacto con canales, sucursal y formulario de consulta.

## Comandos

```bash
npm run dev
npm run build
npm run lint
```

## Personalizacion

Los textos, datos de contacto, servicios, productos e imagenes principales estan centralizados en `src/data/clinic.ts`.
